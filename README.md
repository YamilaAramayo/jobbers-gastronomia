# Jobbers Argentina - Portal de Empleos Gastronómicos & Blog

Plataforma web de reclutamiento y portal de novedades enfocado en el sector gastronómico de Córdoba y Argentina. Permite a postulantes buscar vacantes y consultar recursos del sector, y a empresas/marcas publicar ofertas laborales y patrocinar espacios B2B.

---

## 🚀 Características Principales

- **Buscador de Empleos:** Módulo de búsqueda y filtrado de vacantes para el rubro gastronómico.
- **Blog & Recursos:** Sección con guías de salarios, consejos para CV y tendencias en equipamiento e indumentaria.
- **Publicidad B2B & Sponsors:** Banners integrados para marcas de la industria e integración con Google AdSense.
- **SEO & Metadatos:** Configuración de Open Graph y datos estructurados Schema.org (`Blog`, `JobPosting`).
- **Diseño Responsive:** Interfaz adaptable a dispositivos móviles desarrollada con CSS Grid y Flexbox.

---

## 🛠️ Tecnologías Utilizadas

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla), FontAwesome 6
- **Backend:** PHP 8.x
- **Base de Datos:** MySQL / MariaDB
- **Infraestructura:** Hostinger (hPanel / Apache / SSL)
